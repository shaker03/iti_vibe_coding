# QuickSort Lab Assignment

This project contains the implementation of the QuickSort lab assignment, demonstrating recursive and iterative approaches, alongside MergeSort and the built-in JavaScript sort. It includes a beautiful web visualizer, unit tests with Jest, and an Express REST API backend.

## Structure
- `algorithms/` - Core sorting algorithms.
- `public/` - The frontend web interface.
- `tests/` - Jest unit tests.
- `server.js` - Express backend.

## Getting Started

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Run Tests:**
   ```bash
   npm test
   ```

3. **Start the Application:**
   ```bash
   node server.js
   ```

4. **View Interface:**
   Navigate to `http://localhost:3000` in your web browser.
